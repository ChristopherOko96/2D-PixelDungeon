# Stone golem sprites

`source/golem_sheet.webp` was provided by the project owner on 2026-10-26
(a generated sprite sheet). The frames in this folder are cut from it by
`scripts/slice_golem_sheet.py` (background removed, aligned on body and feet,
scaled 1.9x). Re-run the script after replacing the sheet.

The owner is responsible for the usage rights of the source image.
