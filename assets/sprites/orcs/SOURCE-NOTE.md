# Goblins and orcs

`source/orcs_a.webp` and `source/orcs_b.webp` were provided by the project
owner on 2026-10-26 (generated images, one standing figure per creature).
`scripts/slice_orc_sheets.py` cuts them into the figures in this folder
(background and floor removed, scaled to game height, 1 px outline). The
figures have no animation frames; the game animates them through poses.

The owner is responsible for the usage rights of the source images.
