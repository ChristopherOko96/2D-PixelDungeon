# Stories aus `main` (Nachschlagewerk)

Kopien der Stories 002–011 aus `origin/main` (Bruder, Stand 357d509), unverändert.
Sie beschreiben, wie dort Isaac-Etagen, Kampfgefühl, Bosse, EXP, Hauptmenü,
Klassen, Gegner, Truhen und Nebenbosse umgesetzt sind, inklusive Werten und
Testnachweisen. Sie dienen als Vorlage beim schrittweisen Übernehmen auf
`codex_v2` (Plan: `AGENTS.md`, Abschnitt „Feature decisions“).

Die Nummern überschneiden sich mit den eigenen Stories in
`production/epics/dungeon-rooms/`, deshalb liegen sie hier getrennt. Wo sie den
Entscheidungen vom 27.10.2026 widersprechen (z. B. Perks, Türen, Welten), gelten
die Entscheidungen in `AGENTS.md` und `docs/KLASSEN-FAEHIGKEITEN.de.md`.
